The short answer is no, you cannot use the complete dataset of every possible game because the numbers are too vast—but yes, you can use the complete dataset of every unique board state to do exactly what you are describing.
There is an important distinction in combinatorics between unique board positions (states) and unique games (the chronological paths of moves taken to reach a state).

* Possible Complete Games: There are approximately $8.83 \times 10^{15}$ (8.8 quadrillion) distinct paths/games. Storing the raw historical turn logs for every possible game sequence is beyond the storage capacity of standard local machines. [1] 
* Possible Legal Board States: There are exactly 4,531,985,219,092 (4.5 trillion) reachable board positions. John Tromp strong-solved the game in 1995 by mapping the perfect game-theoretic value (Win, Loss, or Draw) for every single one. Because the state space can fit onto modern multi-terabyte drives using bitmap compression, it forms the perfect complete ground-truth dataset for your training and pruning experiment. [2, 3, 4]

class InstinctConnectFourModel(nn.Module):
    """
    An overparameterized policy network designed to distill a pre-solved 
    Connect 4 game-theoretic engine into pure weights.
    """
    def __init__(self):
        super().__init__()
        # Input: 1 channel, 6 rows, 7 columns board grid state representation
        self.conv_block = nn.Sequential(
            nn.Conv2d(1, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Flatten()
        )
        self.policy_head = nn.Sequential(
            nn.Linear(64 * 6 * 7, 256),
            nn.ReLU(),
            nn.Linear(256, 7) # Output: Action preferences across the 7 columns
        )

    def forward(self, x):
        x = self.conv_block(x)
        return self.policy_head(x)
def apply_global_magnitude_pruning(model, amount=0.2):
