## Part 1: The WGSL Sparse Voxel Projection Shader
This shader takes a stream of active, packed voxel coordinates, decodes their 3D spatial positions, and projects their features directly into a linear embedding space for real-time model evaluation.

struct VoxelParams {
    grid_scale: f32,
    embedding_dim: u32,
    total_active_voxels: u32,
    learning_rate: f32,
};

// Bindings
@group(0) @binding(0) var<storage, read> PackedVoxels: array<u32>;       // Packed: upper 24-bits = XYZ, lower 8-bits = Feature ID
@group(0) @binding(1) var<storage, read> FeatureEmbeddings: array<f32>;  // Static lookup table for voxel types
@group(0) @binding(2) var<storage, read_write> DenseLatentOut: array<f32>; // Flattened output matrix for Transformer
@group(0) @binding(3) var<uniform> params: VoxelParams;

@compute @workgroup_size(64, 1, 1)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let voxel_idx = global_id.x;
    if (voxel_idx >= params.total_active_voxels) { return; }

    // 1. Unpack the voxel data
    let packed_data = PackedVoxels[voxel_idx];
    let feature_id  = packed_data & 0xFFu;          // Extract 8-bit feature index
    let packed_xyz  = packed_data >> 8u;            // Extract 24-bit spatial coordinate

    // 2. Decode 3D spatial components (8 bits per axis: 256x256x256 max resolution)
    let x = f32((packed_xyz >> 16u) & 0xFFu) * params.grid_scale;
    let y = f32((packed_xyz >> 8u) & 0xFFu) * params.grid_scale;
    let z = f32(packed_xyz & 0xFFu) * params.grid_scale;

    // 3. Compute spatial projection offset
    // Maps the 3D voxel index to its starting slice in the linear Transformer sequence
    let output_sequence_offset = voxel_idx * params.embedding_dim;

    // 4. Project features and inject continuous geometric coordinates
    for (var i = 0u; i < params.embedding_dim; i = i + 1u) {
        let embedding_val = FeatureEmbeddings[(feature_id * params.embedding_dim) + i];
        
        // Inject spatial coordinates natively into the feature vector
        var coordinate_bias = 0.0;
        if (i % 3u == 0u) { coordinate_bias = x; }
        else if (i % 3u == 1u) { coordinate_bias = y; }
        else { coordinate_bias = z; }

        // Write directly to the output matrix passed to PyTorch
        DenseLatentOut[output_sequence_offset + i] = embedding_val + coordinate_bias;
    }
}

## Part 2: Mathematical Integration for Downstream Transformers
To feed this spatial stream efficiently into a standard deep learning model without pipeline synchronization delays, the projection output must map directly to continuous matrix formats.
## 1. Coordinate Mapping (Morton/Hilbert vs. Packed Linearization)
To maximize memory locality on the GPU, you can organize the PackedVoxels buffer using a Z-order (Morton) curve sequence rather than a raw list of coordinates. This ensures that voxels that are close to each other in 3D physical space remain adjacent in the GPU memory buffer, maximizing your L1/L2 cache hit rates during the projection pass.
## 2. The Spatial-Injected Loss Loop
When updating the projection parameters during an active inference step, your tracking loss must evaluate both semantic identity and geometric position. The error function E balances feature representation with physical coordinate accuracy:
$$E = \frac{1}{2} \sum_{i=1}^{N} \left\Vert{} \mathbf{e}_{id} + \mathbf{x}_i - \mathbf{t}_i \right\Vert{}_2^2$$ 
Where $\mathbf{e}_{id}$ is the base feature representation from the embedding table, $\mathbf{x}_i$ is the spatial vector decoded by the shader $[x, y, z]$, and $\mathbf{t}_i$ is the target latent vector expected by the Transformer.
## 3. Zero-State Momentum Prediction
Because voxel environments change rapidly across frames, you can pass a Zero-State Momentum predictive flag through the shader. If the structural layout between frame t-1 and frame t matches above a certain percentage, the shader skips the full matrix reallocation step and updates the active memory addresses in place, cutting tensor preparation time to nearly zero.
