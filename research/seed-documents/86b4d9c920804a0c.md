## Core Principles of the Minimal Architecture## 1. Hardware is the Synchronizer (Zero Host Code)
Forget custom messaging queues or WebRTC-style CPU data pipelines. The system relies entirely on a shared Vulkan Timeline Semaphore.

* WebGPU increments the semaphore value when it finishes projecting the sparse 512³ voxels into the VRAM ring slice.
* PyTorch's underlying CUDA stream blocks natively on that exact semaphore value.
* The host CPU never wakes up to copy or move a single byte.

## 2. The 32-bit Unitary Token
We enforce absolute data minimalism at the ingress point. A voxel is never a struct; it is a single u32 integer. Because a 512³ space fits perfectly into a 27-bit Morton index, the remaining 5 bits are wrapped as the material index.

* This allows a single, linear memory array to hold millions of spatial points.
* The GPU's L1/L2 cache hit rates skyrocket because the data structures map perfectly to hardware cache lines.

## 3. In-Flight Weight Blending as a Pass
The in-flight SGD framework is stripped down to an element-wise matrix modification step. Rather than calculating complex global loss functions across deep networks, the engine evaluates drift inside the compute shader via a fast structural variance boundary limit. If the spatial drift breaches the threshold, the weight buffer is mutated in-place on the GPU during the very same compute pass.
