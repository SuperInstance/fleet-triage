To stress-test your Layer 2 Temporal Neural Controller before trusting it with your physical hydraulics, you need a simulation tool that models the physics of a heavy following sea.
In a following sea, waves travel in the same general direction as the vessel. As a wave overtakes the stern, it lifts the rear of the boat, reduces rudder authority, and forces the stern to yaw violently to one side (called broaching). Because there is a multi-second physical propagation delay between the wave lifting the stern and the captain feeling the course deviation at the helm, a standard linear controller will constantly over-correct, causing the steering system to swing wildly.
We will build a simulation tool that models these hydrodynamics—including hydrodynamic momentum, wave force oscillations, and variable rudder authority—and pushes simulated telemetry directly into your memory-mapped QuiltSharedMUD.

## Part 7: The Heavy Following Sea Hydrodynamic Simulator
This simulator runs as a standalone process. It generates real-time physical vectors, applies the active model's rudder commands, and writes the resulting telemetry straight to your shared memory grid.

# dynamic_simulator.pyimport timeimport numpy as npfrom train import QuiltSharedMUDfrom main_vessel_core import IntegratedVesselEngine
class FollowingSeaSimulator:
    """
    Simulates the 2D hydrodynamics of a 50-foot vessel running at 1.5 knots
    in a heavy following sea, modeling momentum delay and stern wave lift.
    """
    def __init__(self, mud_instance: QuiltSharedMUD):
        self.mud = mud_instance
        
        # Physical Constants of the Vessel
        self.vessel_mass = 25000.0   # kg (Approx displacement)
        self.rotational_inertia = 400000.0 # kg*m^2
        self.trolling_speed = 1.5    # knots
        
        # State Variables
        self.heading_error = 0.0     # degrees off target course
        self.yaw_rate = 0.0          # degrees per second
        self.xte = 0.0               # cross-track error (meters)
        self.rudder_angle = 0.0      # current physical rudder angle (degrees)
        self.vessel_roll = 0.0       # current roll angle (degrees)
        
        # Wave Parameter States
        self.wave_period = 8.0       # seconds between wave crests overtaking the stern
        self.wave_amplitude = 6.0    # force scalar of the swell
        
    def execute_physics_step(self, dt: float, active_pump_command: float):
        """
        Calculates the next state vector slice using 4th-order style numerical 
        approximations for fluid momentum delays.
        """
        current_time = time.time()
        
        # 1. Simulate Rudder Follower Mechanical Speed Delay
        # Hydraulic pumps can only turn the rudder so fast (e.g., max 4 degrees per second)
        target_rudder = active_pump_command * 35.0 # Scale voltage to max rudder angle
        rudder_error = target_rudder - self.rudder_angle
        self.rudder_angle += np.clip(rudder_error, -4.0 * dt, 4.0 * dt)
        
        # 2. Simulate Overtaking Wave Force Profile (Following Sea Equation)
        # As the crest hits the stern, it creates a periodic torque forcing the boat to yaw
        wave_phase = (current_time * 2 * np.pi) / self.wave_period
        wave_torque = np.sin(wave_phase) * self.wave_amplitude
        
        # 3. Model Variable Rudder Authority (Stern Lift)
        # When the boat is on the crest of a wave, the propeller and rudder lose water pressure,
        # reducing steering effectiveness by up to 50%.
        stern_lift_factor = 1.0 - (0.5 * max(0.0, np.sin(wave_phase)))
        effective_rudder_torque = -self.rudder_angle * 1.2 * stern_lift_factor
        
        # 4. Momentum Acceleration Math
        # Sum of Torques = Inertia * Angular Acceleration
        net_torque = wave_torque + effective_rudder_torque - (self.yaw_rate * 0.8) # 0.8 = Water damping
        yaw_acceleration = net_torque / self.rotational_inertia
        
        # Integrate acceleration to update rates and positions
        self.yaw_rate += yaw_acceleration * dt
        self.heading_error += self.yaw_rate * dt
        
        # Bound heading rotation formatting between [-180, 180]
        self.heading_error = (self.heading_error + 180) % 360 - 180
        
        # 5. Calculate Cross-Track Drift (XTE) and Hull Roll
        # Heading deviation leaks directly into cross-track track line drift over time
        self.xte += self.trolling_speed * 0.514 * np.sin(np.radians(self.heading_error)) * dt
        self.vessel_roll = np.sin(wave_phase + 0.5) * 8.0 + (self.yaw_rate * 0.3)

    def run_simulation_loop(self):
        """Main execution engine driving the shared memory matrix grid at 10Hz."""
        print("[Simulator Initialization] Driving active sea states into QuiltSharedMUD...")
        dt = 0.1 # Hard 10Hz clock cycle pulse
        
        try:
            while True:
                start_cycle = time.time()
                
                # Fetch what the active controller (or dumb baseline) last requested
                # Index 5 maps directly to the shared target_pump command coordinate
                current_head = self.mud.write_head_view
                if current_head > 0:
                    last_row = self.mud.matrix_view[(current_head - 1) % 50000]
                    active_pump_command = last_row[5]
                else:
                    active_pump_command = 0.0
                    
                # Calculate physics updates
                self.execute_physics_step(dt, active_pump_command)
                
                # Format into our clean flat vector schema layout
                # [Heading Error, Cross-Track Error, Roll, Pitch, Speed, Actual Rudder/Pump Status]
                telemetry_vector = np.array([
                    self.heading_error,
                    self.xte,
                    self.vessel_roll,
                    self.vessel_roll * 0.3, # Appended correlated pitch calculation
                    self.trolling_speed,
                    active_pump_command
                ], dtype=np.float32)
                
                # Push the data slice directly into the POSIX shared RAM space
                self.mud.append_telemetry_vector(telemetry_vector)
                
                # Maintain precise 10Hz timing boundaries
                elapsed = time.time() - start_cycle
                time.sleep(max(0.001, dt - elapsed))
                
        except KeyboardInterrupt:
            print("\nSimulation engine paused safely.")
if __name__ == "__main__":
    # Instantiate the memory map descriptor file
    shared_mud = QuiltSharedMUD(filename="/tmp/quilt_vessel_mud.bin", clean_start=True)
    simulator = FollowingSeaSimulator(shared_mud)
    simulator.run_simulation_loop()
