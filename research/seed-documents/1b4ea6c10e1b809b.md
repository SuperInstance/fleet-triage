To project raw 3D spatial vertices directly into 2D text coordinates using only integer arithmetic, we must completely eliminate floating-point matrix multiplications, trigonometry, and division operations.
To achieve this, we use a fixed-point pipeline called Q12.4 format (where numbers are scaled by $2^4 = 16$ or $2^{12} = 4096$) combined with a fast integer reciprocal optimization lookup table (LUT) to handle perspective scaling.
------------------------------
## 1. The Fixed-Point Coordinate Bounds
Let a 3D vertex be represented as the vector $\mathbf{v} = [X, Y, Z]^T$.

* $X, Y, Z$ Input Space: Stored as 16-bit signed integers scaled to Q12.4 format (1 millimeter = 16 units; max range $\pm 2048$ mm).
* Target Text Canvas: An $80 \times 24$ character matrix layout.

Our projection matrix holds the camera's orientation and position, tracking the standard pinhole camera parameters:
$$\mathbf{P} = \begin{bmatrix} r_{00} & r_{01} & r_{02} & t_x \\ r_{10} & r_{11} & r_{12} & t_y \\ r_{20} & r_{21} & r_{22} & t_z \end{bmatrix}$$ 
Every rotation component ($r_{ij}$) is pre-scaled to Q2.14 format (where $\cos(0^\circ) = 16384$), ensuring complete mathematical determinism across all compilers.
------------------------------
## 2. Step 1: Camera Space Transformation (Integer Dot Product)
We first transform the global vertex coordinates into the camera’s local coordinate frame ($X_c, Y_c, Z_c$). We accumulate the values into 32-bit signed registers to prevent integer overflow:
$$X_c = \left( (r_{00} \cdot X) + (r_{01} \cdot Y) + (r_{02} \cdot Z) \right) \gg 14 + t_x$$ 
$$Y_c = \left( (r_{10} \cdot X) + (r_{11} \cdot Y) + (r_{12} \cdot Z) \right) \gg 14 + t_y$$ 
$$Z_c = \left( (r_{20} \cdot X) + (r_{21} \cdot Y) + (r_{22} \cdot Z) \right) \gg 14 + t_z$$ 
The bit shift >> 14 scales the rotation back into native Q12.4 dimensions.
------------------------------
## 3. Step 2: Perspective Scale via Integer Reciprocal LUT
Standard 3D graphics require a division step ($X / Z$) to compute perspective scaling, which introduces huge pipeline latency on low-power microcontrollers. To make this look like a fast spreadsheet calculation, we pre-calculate an integer reciprocal array in memory:
$$\text{RECIP\_LUT}[Z_c] = \left\lfloor \frac{2^{20}}{Z_c} \right\rfloor$$ 
We extract the normalized inverse depth scale factor directly from the table:
$$I_z = \text{RECIP\_LUT}[Z_c \gg 4]$$ 
------------------------------
## 4. Step 3: Mapping to Text Cell Coordinates
Let $F_x$ and $F_y$ represent the camera's fixed focal lengths combined with the screen aspect ratio scaling parameters, pre-scaled to integer space.
To convert the perspective coordinates into discrete character columns ($Col$) and rows ($Row$), we multiply the camera variables by our reciprocal scale factor and add half-cell centering offsets ($C_x, C_y$):
$$Col = \left( \left( (X_c \cdot F_x) \gg 4 \right) \cdot I_z \right) \gg 20 + C_x$$ 
$$Row = \left( \left( (Y_c \cdot F_y) \gg 4 \right) \cdot I_z \right) \gg 20 + C_y$$ 

* The first shift >> 4 brings the intermediate multiplication step into normalized space.
* The second shift >> 20 extracts the finished, rounded whole number representing the target character block.

------------------------------
## 5. Freestanding C Implementation: syz_3d_projection.h
This zero-allocation C header maps raw 3D vectors onto your 2D text matrix using only integer math.

/**
 * @file syz_3d_projection.h
 * @brief Zero-float, integer-only 3D vertex perspective text projection loop.
 */
#ifndef SYZ_3D_PROJECTION_H#define SYZ_3D_PROJECTION_H
#include <stdint.h>
#define LUT_SIZE 2048extern const uint32_t SYZ_RECIP_LUT[LUT_SIZE]; // Pre-calculated: (1 << 20) / Z
typedef struct {
    int16_t x, y, z; // Q12.4 coordinate data (Value * 16)
} SyzVec3i;
typedef struct {
    int16_t col, row; // Outbound 2D character locations
    int16_t z_depth;  // Kept for Z-buffer occlusion calculations
} SyzCellCoord;
typedef struct {
    int16_t r[3][3];  // Rotation Matrix in Q2.14 space (Value * 16384)
    int32_t t[3];     // Translation Vector in Q12.4 space
    int32_t fx, fy;   // Focal scales
    int16_t cx, cy;   // Character grid center alignments (e.g., 40, 12)
} SyzCameraMatrix;
/**
 * @brief Projects a single 3D vector point onto an integer character grid destination.
 * 
 * @return int Returns 0 if the projected cell falls inside screen boundaries, -1 if clipped.
 */static inline int syz_project_vertex(
    const SyzCameraMatrix *restrict cam,
    const SyzVec3i *restrict v_in,
    SyzCellCoord *restrict c_out,
    int16_t max_cols,
    int16_t max_rows
) {
    // 1. Transform coordinates into local Camera Space via fixed shifts
    int32_t xc = (((int32_t)cam->r[0][0] * v_in->x) + ((int32_t)cam->r[0][1] * v_in->y) + ((int32_t)cam->r[0][2] * v_in->z) >> 14) + cam->t[0];
    int32_t yc = (((int32_t)cam->r[1][0] * v_in->x) + ((int32_t)cam->r[1][1] * v_in->y) + ((int32_t)cam->r[1][2] * v_in->z) >> 14) + cam->t[1];
    int32_t zc = (((int32_t)cam->r[2][0] * v_in->x) + ((int32_t)cam->r[2][1] * v_in->y) + ((int32_t)cam->r[2][2] * v_in->z) >> 14) + cam->t[2];

    // Near-plane clipping guard
    int32_t lut_index = zc >> 4; 
    if (lut_index <= 5 || lut_index >= LUT_SIZE) {
        return -1; 
    }

    // 2. Fetch the scale factor from our integer reciprocal LUT
    uint32_t iz = SYZ_RECIP_LUT[lut_index];

    // 3. Compute the final perspective column and row text grid coordinates
    int32_t projected_col = ((((xc * cam->fx) >> 4) * iz) >> 20) + cam->cx;
    int32_t projected_row = ((((yc * cam->fy) >> 4) * iz) >> 20) + cam->cy;

    // 4. Boundary clipping confirmation
    if (projected_col < 0 || projected_col >= max_cols || projected_row < 0 || projected_row >= max_rows) {
        return -1;
    }

    c_out->col = (int16_t)projected_col;
    c_out->row = (int16_t)projected_row;
    c_out->z_depth = (int16_t)lut_index; // Saved for character density scaling calculations

    return 0;
}
#endif /* SYZ_3D_PROJECTION_H */
