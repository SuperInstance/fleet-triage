The ceiling, and what the original number actually meant

3×3 tic-tac-toe, 5-fold cross-validated. Variance is across data folds, not seeds — seed variance was exactly 0 for every model, and a zero-variance result is inconclusive, never a pass.

modeltop-1, single-optimallift over chance
random empty cell (floor)0.4206 ± 0.0284—
linear 9×90.5708 ± 0.01751.36×
decision tree, depth 160.6793 ± 0.02891.62×
exact solver (ceiling)1.00002.38×

The linear model reaches 0.840 of the best tree. So the original headline — "0.1807" — was never "a neural net is bad at minimax." It was "a linear map is bad at minimax," which is true and much less interesting, and it was reported without the number that would have said so.

A number without a ceiling is not a result. It is a number.

The penalty is real for the linear model (39.7% → 22.6%) and absent for the tree (55.5% → 56.7%). It is a property of additivity, not of the task. And the naive version of this contrast has the wrong sign, because a position with two own threats is structurally a late position with a high chance level already.

What the measurement got wrong about itself

A census of 500 repos flagged 106 as bloated by git history. 36 were real. The signal divided by src_bytes, which is zero for any repo with no source files — so every docs-only and media-only repo was flagged by construction. A ratio whose denominator can be zero is not a measurement; it is a construction that always produces a finding.

Found by refusing to accept an impossible number: one repo reported 344 MB of files inside a 291 MB repo. It was not a GitHub quirk. The instrument was wrong, and it was mine.

A second one: I had carried 180,361 reachable states for a 3×3 board. A 3×3 board has 3⁹ = 19,683 distinct states, so even labelling every one with whose-turn gives at most 39,366. The figure exceeded the entire state space by 4.6×. The real numbers: 5,478 reachable, 2,423 with us to move, and 48.6% — not 14.7% — have more than one optimal move.

A verification layer that did not verify anything. voxelglyph shipped 7 pins, all green — and never once executed the experiment it was verifying. Measured with an atexit counter: 0 executions. Two mutations of the flagship line survived: turning max() into min() (so the product reported the narrowest class as the widest blind spot) and coarsening the sweep from 140,608 triples to 8.

The worst of them was a test named test_weights_sum_256 whose body asserted 77 + 150 + 29 == 256 — arithmetic on literals in its own source. Setting the real weights to something summing to 294 left it green. A test whose name asserts a property of the product while its body asserts nothing about the product is worse than no test.

Fixed: the product now returns its result, the path is no longer hardcoded to one machine, and all three mutations now fail. 11 tests, green.
